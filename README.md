Для запуска:
1. Открыть 2 терминала
2. В 1 терминале прописать путь к Client ( C:\Users\Administrator\Desktop\messenger\client )
3. В 2 терминале прописать путь к Serser ( C:\Users\Administrator\Desktop\messenger\server )
4. Сначала запускаем сервер ( cargo run --release )
5. После Сервера Клиент ( cargo run --release )
